Transacciones en MySQL

5. Glosario de términos

Texto


ACID
Acrónimo de Atomicidad, Consistencia, Aislamiento y Durabilidad; conjunto de propiedades que garantizan transacciones seguras.
Atomicidad
Propiedad que asegura que una transacción es indivisible: o se completa totalmente o no se aplica ningún cambio.
Autocommit
Variable de sistema que determina si los cambios en la base de datos se confirman automáticamente tras cada sentencia SQL.
COMMIT
Comando TCL que hace permanentes todos los cambios realizados durante la transacción actual.
DML
Data Manipulation Language; parte de SQL (SELECT, INSERT, UPDATE, DELETE) dedicada a la manipulación de datos.
Deadlock
Situación en la que dos transacciones se bloquean mutuamente de forma permanente al esperar recursos que la otra posee.
InnoDB
Motor de almacenamiento predeterminado en MySQL que soporta transacciones, integridad referencial y bloqueos a nivel de fila.
MVCC
Multi-Version Concurrency Control; técnica de InnoDB que mantiene versiones antiguas de filas para permitir lecturas sin bloqueos.
ROLLBACK
Comando que deshace todos los cambios realizados en la transacción actual, devolviendo la base de datos a su estado anterior.
SAVEPOINT
Identificador interno de una transacción que permite realizar retrocesos parciales de los datos.
TCL
Transaction Control Language; conjunto de comandos (COMMIT, ROLLBACK, etc.) usados para gestionar el flujo de las transacciones.
Trigger
Objeto de base de datos asociado a una tabla que se ejecuta automáticamente ante eventos de inserción, actualización o borrado.
Undo Log
Registro de cancelación donde se guardan las versiones anteriores de los datos modificados para permitir el rollback y la consistencia de lectura.
